# Stitch Counter

A hands-free stitch and row counter for knitting and crochet, with a flip-clock display and voice commands.

**Live:** https://valerielui.github.io/stitch-counter/

## Voice commands

| Say | Does |
| --- | --- |
| "add one" / "plus one" / "one more" | +1 stitch |
| "minus one" / "take one off" / "one less" | −1 stitch |
| "next row" / "new row" | Go to the next row (stitches reset to 0) |
| "restart row" / "start over" / "start the row over" / "redo this row" | Set stitches to 0 on the same row |
| "undo" | Undo the last action |

> Voice control uses the Web Speech API, so it needs **Chrome or Safari** and an **internet connection**. The on-screen buttons work everywhere.
